## 一、交付清单

### 1. 管理群转发（plugins/ncc_community/forward.py）
管理群 = 「NCC 社群管理肥肉售后维权🤖」，**群内成员即管理员**，无需私聊验证。

在管理群里发指令：

| 指令 | 作用 |
|---|---|
| `转发 测试组` | 进入收集模式，之后你发的每条消息（文字/图/视频/文件/链接卡片）实时群发到分组内所有群 |
| `结束` / `取消` | 收工（结束会汇报成功/失败条次；闲置 5 分钟自动结束） |
| `分组列表` | 查看分组及目标群 |
| `新建分组 X` `删除分组 X` `加群 分组\|群名` `删群 分组\|群名` | 分组维护（带空格的群名用竖线分隔） |
| `检查群组 分组名/全部` | 逐群试连通，报出改名失联的群 |
| `帮助` | 完整指令表 |

- 多管理员可同时各转各的（会话按发送人隔离）。
- 转发用 wxauto 的 `msg.forward(多目标)`，超过 8 个群自动分批。
- **机器人微信号自己在管理群发指令也有效**（手机登着机器人号就能操作）。
- 分组配置在 `plugins/ncc_community/data/config.json`，指令改动实时落盘。

### 2. 迎新卡片 + 关键词拉群（welcome.py / invite.py）
- **迎新**：新人进群 → 发定制文案（`{name}` 替换昵称）→ 发在地化链接卡片（`SendUrlCard`）。每群独立配置，管理群里用 `设迎新文案` `设迎新链接` `开迎新/关迎新` 维护。已给两个测试群配了样例。
- **拉群**：群里或私聊发关键词（当前配了 `测试拉群` → 肥肉测试1）→ 机器人把人拉进目标群。每人每关键词每天限 3 次。管理群里用 `设拉群 关键词|目标群` 维护。
- UI 协议边界（重要）：**只能拉机器人的好友**（微信选人框机制）；非好友会收到引导语"先加我好友"。好友自动通过已修复，所以流程是通的。群超 200 人后对方需点确认卡片（微信机制）。

### 3. NCC 知识库（mac-mini，爱因斯坦方案）
```
355 篇公众号文章 → 2175 个语块 → OpenRouter 免费嵌入(2048维) → Qdrant
微信群 @肥肉 → 机器人 DusAPI → mac-mini rag_proxy(:8434, OpenAI兼容)
              → 检索+重排 → 归集Key(lowcostaiapi, gpt-5.5) → 回答进群
```
- 部署在 `mac-mini:~/ncc-kb/`（Qdrant arm64 原生二进制 + Python venv，零 Docker 零 sudo）。
- 两个 launchd 服务 `com.ncc.qdrant` / `com.ncc.ragproxy`：开机自启、崩溃自拉起。
- **facts.md 机制**：`~/ncc-kb/facts.md` 里的内容每次问答全量注入——据点/主理人/WiFi 这类"必须答对"的小事实放这里，**目前是占位模板等你填**，填完即时生效不用重启。
- 实测问答（"大理据点怎么来的？主理人是谁？"）：正确说出 2023 年 5 月建立、三月街赛马场附近三层白族大院、主理人大曹，且资料没有的部分明确说不确定。延迟 14-18 秒。

### 4. 机器人接入（config + prompt）
- 新增 API 条目 #3：`ncc-kb → http://100.71.182.5:8434`（DusAPI 流式，600s 超时）。

## 三、夜间事故与整改（重要）

**事故**：我写的面板重启脚本按"端口 1000x"杀进程，误杀了微信客户端（微信本地也监听这类端口），微信掉到登录页。你凌晨手工重新登录了一次。
**整改**：
1. 重启脚本已改为只杀「进程名 python.exe 且命令行含 web_server.py」，永不按端口杀；
2. 「微信进程绝对不碰、登录必须人工」已写入我的长期记忆；
3. 新增两个计划任务：`SWXPanelRestart`（在你的 RDP 会话里安全重启面板）、`SWXRun`（会话 2 通用执行器），以后改核心代码不再需要你到桌面操作。
